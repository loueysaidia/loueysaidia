## Featured Projects

### SmartCabinet: Medical Clinic Management SaaS
`PHP` `Laravel` `PostgreSQL` · *In development*

- Designing and building a multi-module platform covering patient records, doctor profiles, appointment scheduling and walk-in queue handling.
- Implementing secure authentication and role-based authorization to separate clinic staff, doctors and administrator access levels.
- Modeling a relational schema for multi-clinic data, including prescriptions, medical documents, invoices and subscription plans.
- Building REST API endpoints for appointment booking, billing and notifications, with input validation and error handling.

### Secure Vote System
`Python` `FastAPI` `RSA Encryption`

- Developed a secure online voting platform with RSA encryption to protect vote confidentiality and integrity.
- Built authentication and ballot-management logic that prevents duplicate voting and maintains an audit trail.
- Designed encrypted result computation that preserves voter anonymity while enabling verifiable tallying.

### Warehouse Administrator System
`Python` `Django` `MySQL`

- Built a Django web application for warehouse inventory and product management, with CRUD operations for stock and administrative user roles.
- Designed a relational MySQL schema to track inventory levels and product data.

### Daycare Management System
`Python` `FastAPI` `MySQL`

- Developed a FastAPI backend handling student records, attendance tracking and parent communication.
- Authored project management documentation (WBS, PERT/GANTT scheduling, UML design) as part of an academic software engineering process.

### Blood Bank Management System
`Node.js` `Express.js` `MySQL`

- Built a Node.js/Express.js backend for donor registration, blood inventory tracking and hospital blood requests.
- Designed a relational MySQL schema to track donor records and stock availability.

### Salary Calculator
`Python` `FastAPI` `MySQL`

- Built a backend application that computes employee salaries with automated tax and deduction logic, generating payroll reports and salary slips.
