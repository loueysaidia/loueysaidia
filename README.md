## About
 
I am a computer science engineering student specializing in Artificial Intelligence, building towards a career as a backend and AI engineer. I enjoy designing web APIs and data-driven applications, and I have built several full-stack management systems using Python, PHP and JavaScript frameworks.
 
My work so far focuses on:
 
- **Backend development**: REST APIs, authentication and authorization, CRUD workflows, and role-based access control with FastAPI, Django, Laravel and Express.js.
- **Data and databases**: relational design and data modeling with MySQL and PostgreSQL, plus working knowledge of MongoDB.
- **Applied security**: RSA-based encryption and secure application design, applied in an online voting system.
- **AI foundations**: machine learning fundamentals, computer vision and data analysis with the Python scientific stack.
- **Project methodology**: UML modeling and project planning with WBS, PERT and GANTT.
I am looking for a junior or internship position where I can contribute to backend or AI projects and keep learning from experienced engineers.
